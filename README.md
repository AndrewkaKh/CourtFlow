# CourtFlow — MVP бронирования кортов Tennis.ru

Карта клуба в 2.5D: наведение подсвечивает корт, клик открывает карточку с фото, ценой и
свободными слотами. Бронь проходит путь «слот → контакты → оплата → подтверждение».
Слот удерживается 10 минут на время оплаты, двойная бронь запрещена на уровне базы.

## Запуск на Windows

Нужен Python 3.10 или новее.

Быстрый путь — дважды кликнуть `start.bat`. Он создаст окружение, поставит зависимости и
запустит сервер. Вручную то же самое:

```powershell
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements-dev.txt
copy .env.example .env
python run.py
```

Откройте http://127.0.0.1:8000. Документация API: http://127.0.0.1:8000/api/docs.

Тесты: `python -m pytest`.

## Как проверить руками

1. Выберите день и время в поле «Свободно в»: занятые корты погаснут.
2. Нажмите на яркий корт, выберите слот, нажмите «Забронировать».
3. Введите имя и телефон, отметьте согласие, нажмите «Перейти к оплате».
4. Нажмите «Оплатить тестовой картой». Появится номер брони, слот станет занятым.
5. Попробуйте забронировать тот же слот во второй вкладке: сервер ответит «Этот слот только что заняли».

Оплаченные брони пишутся в консоль сервера строкой «Оплачена бронь CF-…».
База лежит в `var/courtflow.sqlite3`. Чтобы начать с чистого листа, удалите папку `var`.

## Оплата через песочницу ЮKassa

По умолчанию `PAYMENT_PROVIDER=mock`: оплата подтверждается кнопкой на сайте.
Для настоящего тестового магазина:

1. В личном кабинете ЮKassa создайте тестовый магазин и выпустите секретный ключ.
2. В `.env` укажите `PAYMENT_PROVIDER=yookassa`, `YOOKASSA_SHOP_ID` и `YOOKASSA_SECRET_KEY`.
3. Перезапустите сервер. Кнопка оплаты откроет страницу ЮKassa, тестовые карты есть в её документации.

После оплаты ЮKassa вернёт пользователя на `PUBLIC_URL/?booking=…`, и сайт сам сверит статус платежа.
Вебхук `POST /api/payments/yookassa/webhook` заработает, когда сайт будет доступен из интернета.

## Яндекс Метрика

Укажите номер счётчика в `METRIKA_ID`. Цели воронки: `map_open`, `court_open`, `slot_pick`,
`form_submit`, `payment_start`, `booking_paid`.

## Структура

```
backend/            сервер на FastAPI
  config.py         настройки из .env
  db.py             схема SQLite, уникальный индекс против двойной брони
  courts.py         справочник кортов и тарифов
  schedule.py       занятость, удержание слота, демо-занятость
  payments.py       оплата: mock и ЮKassa
  routes/api.py     HTTP API
  main.py           сборка приложения
data/courts.json    37 кортов по схеме клуба: id, зона, координаты на карте, тариф, фото
frontend/           статический фронт без сборки
  index.html
  css/styles.css
  js/api.js         единственное место, где фронт обращается к API
  js/store.js       расписание и цены поверх ответа API
  js/map.js         карта: отрисовка, зум, перетаскивание, наклон
  js/panel.js       разметка панели по шагам брони
  js/analytics.js   Яндекс Метрика
  js/app.js         состояние страницы и обработчики
  privacy.html, offer.html   черновики юридических текстов
tests/test_api.py   сценарий брони, двойная бронь, истечение удержания, валидация
run.py              запуск сервера
start.bat           установка и запуск в один клик
```

## Что дальше

- Фото кортов: положить в `frontend/img/courts/` и прописать пути в `photos` у корта в `data/courts.json`.
- Уведомление администратору: место отмечено в `mark_paid` в `backend/routes/api.py`.
- Итерация 2: бэкенд на Go реализует тот же API, на фронте меняется только `js/api.js`.
- `DEMO_SEED=0` выключает выдуманную занятость, когда появятся настоящие брони.
